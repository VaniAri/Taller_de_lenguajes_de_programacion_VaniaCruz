# Sesión 6 - Fundamentos de SQL y MySQL

## Descripción

En esta sesión se trabajó con MySQL y SQL para crear y administrar
una base de datos relacional llamada `gamestore_db`.

Se crearon las tablas:

- estudiantes
- recompensas
- historial_canjes

También se realizaron operaciones de inserción, consulta y actualización
de datos, además de una consulta JOIN para relacionar las tablas.

## Archivos

- `Informe_Sesion_6.pdf` → Contiene las evidencias y capturas de la sesión.
- `Sesion6_GameStore.sql` → Contiene el código SQL utilizado.

## Tecnologías utilizadas

- MySQL
- SQL
- phpMyAdmin
